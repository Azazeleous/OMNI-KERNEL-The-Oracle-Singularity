Adapt this brief to your own offer. The downloadable kit includes the build tools, checks, and GitHub Actions workflow.

A professional landing-page prompt

Design a landing page for [product] serving [audience].
Primary benefit: [a specific, supportable outcome].
Primary action: [one working destination].
Evidence: use only supplied facts and approved assets.
Structure: offer, benefits, real proof when available,
how it works, relevant FAQ, and a final call to action.
Style: one coherent palette, clear type, generous spacing.
Keep it responsive at 320px, keyboard accessible,
and usable with reduced motion. Do not invent reviews,
customer logos, performance claims, or prices.

How does this connect to AIDesigner?

Use the brief in AIDesigner, refine the result, and export the code. The kit documents its public generation and refinement process and adds independent release checks.

What does the GitHub Pages workflow publish?

It builds and checks the site, then uploads the dedicated output directory. The deployment job runs only on the production branch or an explicit production workflow run.

Read GitHub's Pages workflow guide

Do the checks prove every aspect of quality?

Automated checks catch specific accessibility, layout, asset, and source risks. A person still needs to review the offer, factual claims, visual hierarchy, and behavior with assistive technology.
