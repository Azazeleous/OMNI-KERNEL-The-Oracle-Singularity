## Generation prompt

Design an original professional landing page for the product described above.
Make the offer and primary action clear in the first viewport. Use a consistent
type scale, spacing system, palette, and layout. Place real proof near the
claim it supports; omit proof sections when evidence has not been supplied.
Include the benefits, a short explanation of the process, relevant FAQ, and
a final primary action. Omit pricing when no approved price is supplied.

Use semantic HTML, one h1, descriptive links, visible focus, readable contrast,
and 44px or larger primary controls. Make the layout work at 320, 390, 768, and
1440 pixels. Respect reduced motion and browser zoom. Keep important content
available without JavaScript. Avoid autoplay, scroll hijacking, fake form
success, invented statistics, and unsupported customer logos or testimonials.

Provide HTML with local CSS and JavaScript assets suitable for a project
subpath on GitHub Pages. Do not depend on Tailwind's browser CDN in the release.
If Tailwind classes are exported, compile them locally or normalize the design
into local CSS before running the checks.

## Refinement passes

1. **Clarity:** shorten the headline, explain the benefit, and remove competing
   actions. Ask a person unfamiliar with the offer what the page does.
2. **Composition:** align the grid, establish a type hierarchy, and make mobile
   spacing intentional. Keep one recognizable visual idea.
3. **Evidence:** verify claims against approved sources and remove unsupported
   proof. Check every CTA destination and any real backend interaction.
4. **Accessibility:** inspect keyboard order, focus, text enlargement, contrast,
   reduced motion, and reading order. Review with assistive technology.
5. **Delivery:** localize assets, check project-relative paths, scan the built
   artifact, and run the browser checks. Retest after every material change.
